# Galaga Gimmick Edition

This repository contains a tiny browser-based shooter inspired by **Galaga**.
Move with the arrow keys, shoot with **Space**, and unleash a screen-clearing
**Mega Bomb** with the **Z** key. The bomb has a short cooldown, introducing a
special gimmick to the classic formula.

## How to Play
1. Open `index.html` in a modern web browser.
2. Use the arrow keys to move your ship.
3. Press **Space** to fire.
4. Press **Z** to trigger the Mega Bomb gimmick.

Enjoy!
